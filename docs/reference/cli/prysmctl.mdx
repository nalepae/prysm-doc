`prysmctl` is Prysm's tool for one-off operator tasks. The task pages show it in use:

- Exit a validator (`prysmctl validator exit`): [Exit a validator](/validators/exit/)
- Set a withdrawal address on `0x00` credentials (`prysmctl validator withdraw`): [Withdrawals and consolidation](/validators/withdrawals/)
- Download a checkpoint state (`prysmctl checkpoint-sync download`): [Checkpoint sync](/setup/checkpoint-sync/)

Slashing protection export and import are part of the `validator` binary, not prysmctl: see [Back up and restore](/operate/backup-and-restore/).

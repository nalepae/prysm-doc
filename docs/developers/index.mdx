This guide is for developers who want to build, run and test Prysm from a clone of the repository. Prysm builds with [Bazel](https://bazel.build/), which downloads its own Go toolchain and every dependency, so a fresh machine needs little more than Bazelisk and `git`.

If you only want to run Prysm, you don't need any of this. Use the [Quickstart](/get-started/quickstart/) and [Install Prysm](/install/) instead.

## Before you begin

- A **Linux** (x86-64 or ARM64) or **macOS** (Apple silicon or Intel) machine. On macOS, install the Xcode Command Line Tools with `xcode-select --install`.
- `git` and a network connection. The first build downloads the toolchains and all dependencies.
- Plenty of free disk space for Bazel's caches, which grow with every configuration you build.

Clone the repository and switch to `develop`, the branch pull requests target:

```bash
git clone https://github.com/OffchainLabs/prysm.git
cd prysm
git checkout develop
```

Run every command in this guide from the root of the clone.

## Cheat sheet

| Task | Command | Page |
| --- | --- | --- |
| Check the Bazel version | `bazel version` | [Install Bazel with Bazelisk](/developers/environment/) |
| Build the beacon node and validator | `bazel build //cmd/beacon-chain //cmd/validator` | [Build with Bazel](/developers/build/) |
| Build an optimized release binary | `bazel build --config=release //cmd/beacon-chain` | [Build with Bazel](/developers/build/) |
| Run the beacon node | `bazel run //cmd/beacon-chain -- --hoodi …` | [Run with Bazel](/developers/run-from-source/) |
| Run one package's tests | `bazel test //beacon-chain/sync:go_default_test` | [Unit tests](/developers/unit-tests/) |
| Run one test | `bazel test //beacon-chain/sync:go_default_test --test_filter=TestName` | [Unit tests](/developers/unit-tests/) |
| Run the presubmit end-to-end test | `bazel test //testing/endtoend:go_default_test` | [End-to-end tests](/developers/e2e-tests/) |
| Update `BUILD.bazel` files | `bazel run //:gazelle -- fix` | [Update BUILD files with Gazelle](/developers/gazelle/) |
| Load a beacon node image into Docker (Linux host) | `bazel run //cmd/beacon-chain:oci_image_tarball` | [Build Docker images](/developers/docker-images/) |

## In this guide

- [Install Bazel with Bazelisk](/developers/environment/): get the Bazel version the repository pins.
- [Build with Bazel](/developers/build/): build the binaries, pick a configuration, find the outputs.
- [Run with Bazel](/developers/run-from-source/): start a beacon node and validator from your checkout.
- [Unit tests](/developers/unit-tests/): run all tests, one package, or a single test.
- [End-to-end tests](/developers/e2e-tests/): run a full private network and check it with evaluators.
- [Update BUILD files with Gazelle](/developers/gazelle/): keep `BUILD.bazel` files and `deps.bzl` in sync with your Go code.
- [Build Docker images](/developers/docker-images/): build the container images and load them into Docker.

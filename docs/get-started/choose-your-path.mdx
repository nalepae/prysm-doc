## Not sure?

- **You want to stake but have never run a node.** Start with [Run a node](/get-started/quickstart/). You need a synced node before your validator can do anything.
- **You want to try without risk.** Do everything on the Hoodi testnet first. See [Try it on Hoodi first](/get-started/try-on-hoodi/).
- **You want to check your hardware.** See [System requirements](/get-started/system-requirements/).
